01 / GitHub 연결

사이트 파일이 올라가 있는 GitHub 저장소 정보를 입력하세요. 토큰은 이 페이지에서만 사용하며 브라우저에 저장하지 않습니다.

보안 안내: 토큰을 다른 사람에게 공유하지 마세요. 이 페이지는 토큰을 localStorage에 저장하지 않으며 GitHub API 요청에만 사용합니다. 테스트가 끝나면 GitHub에서 토큰을 폐기할 수 있습니다.

02 / 새 게임 등록

게임 폴더를 직접 업로드하거나, 100MB 이상 대용량 파일은 외부 서버의 직접 다운로드 URL을 등록할 수 있습니다. 타이틀 이미지는 파일 또는 이미지 URL로 지정할 수 있습니다.

이미지 파일을 직접 올리거나 아래 이미지 URL을 입력하세요.
게임 폴더 전체를 선택하거나 실행 파일과 DATA 폴더 등을 함께 선택하세요.ZIP 파일을 선택하면 내부 파일을 자동으로 읽어 게임 파일로 등록합니다. ZIP은 압축 해제된 상태로 저장됩니다.
공개 다운로드가 가능한 실제 파일 주소를 입력하세요. 공유 페이지 주소가 아니라 ZIP/ISO/IMG 등 파일 자체로 연결되는 HTTPS 링크여야 합니다.
MS-DOS 게임은 .jsdos 번들을 자동으로 만들어 윈도우 없이 바로 실행됩니다. 실행 파일이 폴더 안에 있으면 DATA/GAME.EXE 처럼 적으세요.
등록할 게임 정보를 입력하세요.

03 / 실행 방식 안내

이 등록기는 게임의 폴더·이미지·메타데이터를 저장소에 올리거나 외부 파일 URL을 라이브러리에 등록합니다.

중요: 파일 등록과 게임 실행은 별개입니다. DOS는 JS-DOS용으로 준비된 번들이 있어야 바로 실행할 수 있습니다. Windows 95/98 게임은 별도의 Windows 9x 가상 PC 디스크/실행 환경과 게임 호환성 설정이 필요합니다. 외부 URL은 라이브러리에 링크만 저장합니다. 외부 파일 호스트가 직접 다운로드를 허용해야 하며, 브라우저 플레이어에서 파일을 읽으려면 호스트의 CORS 허용도 필요할 수 있습니다. 이 버전은 파일 등록을 시험하는 단계이며 Windows 95/98 자동 실행까지 완성된 것은 아닙니다.
