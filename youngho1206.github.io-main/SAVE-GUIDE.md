# 세이브 호환 가이드 (savebridge.js)

웹 에뮬레이터의 **💾 저장 / 📥 불러오기** 버튼이 아래 두 종류를 다룹니다.

| 종류 | 설명 | 다른 에뮬레이터와 호환 |
|---|---|---|
| ① 게임 내 저장 (SRAM · 메모리카드) | 게임 메뉴의 "SAVE"로 만든 기록 | **대부분 호환** (표준 형식) |
| ② 즉시저장 (Save State) | 화면 그대로 찍어두는 저장 | **같은 코어·같은 버전끼리만** (RetroArch 계열) |

> 다른 에뮬레이터로 옮길 때는 **①을 쓰세요.** ②는 에뮬레이터마다 내부 구조가 달라 대부분 열리지 않습니다.

## 웹 → 다른 에뮬레이터
1. 웹에서 게임 안의 SAVE 메뉴로 먼저 저장
2. 💾 저장 → ① 에서 에뮬레이터에 맞는 확장자 선택 (`.srm` = RetroArch/Lemuroid 계열, `.sav` = 단독 에뮬)
3. 파일 이름은 ROM 이름과 자동으로 같게 만들어집니다. 에뮬레이터의 저장 폴더(또는 ROM과 같은 폴더)에 넣으세요.
   - RetroArch: `saves/` 폴더 (즉시저장 `.state` 는 `states/` 폴더)
4. N64 단독 에뮬(Project64 · Mupen64Plus · M64Plus FZ)은 "N64 단독 에뮬용 묶음(.zip)"을 풀어 `.eep .sra .fla .mpk` 를 쓰세요.

## 다른 에뮬레이터 → 웹
1. 웹에서 **같은 ROM** 으로 게임 시작
2. 📥 불러오기 → 파일 선택 (여러 개·zip 가능). 종류는 자동 판별
3. 확인 창에서 "적용" → 게임이 다시 시작되며 저장 기록이 반영됩니다.

자동 보정: DeSmuME `.dsv` 꼬리말 제거 · DexDrive `.gme` 머리말 제거 · N64 `.eep/.sra/.fla/.mpk` → 통합 `.srm` 합치기 · RetroArch RZIP/RASTATE 즉시저장 해석.

## 기종별 호환 정도
| 기종 | 게임 내 저장 | 비고 |
|---|---|---|
| NES · SNES · GB · GBC · GBA · 메가드라이브 · 마스터시스템 · 게임기어 | ◎ | 원본 SRAM 그대로 |
| NDS | ○ | 원본 .sav (DeSmuME .dsv 자동 처리) |
| PlayStation | ○ | 128KB 메모리카드 (.srm/.mcd/.mcr) |
| N64 | ○ | libretro .srm ↔ 단독 에뮬 조각 자동 변환 |
| Sega CD · Saturn · 32X · 3DO · Jaguar · PC Engine · Lynx · VB · NGP · 아타리2600 | △ | 에뮬레이터마다 형식이 달라 보장 불가 |
| 마메게임(아케이드) | — | 게임 내 저장 없음, 즉시저장만 |

## 한계 (꼭 읽어주세요)
- 이 사이트에서 실행되지 않는 기종(PSP · PS2 · PS3 · GC · Wii · 3DS · Switch · Xbox · 드림캐스트 등)은 웹에서 세이브를 만들거나 읽을 수 없습니다.
- 에뮬레이터마다 저장 폴더·이름 규칙이 달라, 파일을 올바른 위치에 넣는 것은 사용자가 해야 합니다. (Lemuroid·Delta 등 앱 내부 저장소를 쓰는 앱은 해당 앱의 가져오기/동기화 기능을 확인하세요.)
- GBA는 에뮬레이터마다 저장 파일 크기가 다를 수 있어, 크기가 다르면 확인 창이 뜹니다.
- 적용 후 "적용 확인 불가" 경고가 뜨면 게임을 직접 다시 시작해 보세요.
