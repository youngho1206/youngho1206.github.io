[BIOS 폴더 사용법]
CD 기반 기종은 바이오스 파일이 있으면 더 잘 실행됩니다. 이 폴더에 파일을 올려 두면 게임을 시작할 때 자동으로 찾아서 사용합니다.
(바이오스는 본인이 합법적으로 소유한 것만 사용하세요. 이 사이트는 바이오스·게임 파일을 제공하지 않습니다.)

세가 CD   : bios_CD_U.bin  (또는 bios_CD_E.bin / bios_CD_J.bin)
세가 새턴 : saturn_bios.bin (또는 sega_101.bin / mpr-17933.bin)
3DO       : panafz10.bin    (또는 panafz1.bin)

* 세가 32X · 아타리 재규어는 바이오스 없이 실행됩니다.
* 파일 이름은 위와 똑같이(대소문자 포함) 올려야 합니다.
* GitHub Pages 에 올린 뒤에 동작합니다. (내 컴퓨터에서 더블클릭으로 열면 찾지 못합니다)
