[webthema 폴더 사용법]

1) 테마 파일을 이 폴더에 올리세요.
   이름 규칙:  theme01.html, theme02.html, theme03.html ...  (thema01.html 처럼 써도 됩니다)
   번호 순서대로 찾고, 연속 3개가 비어 있으면 거기서 멈춥니다.
   → 설정 › 테마 추가 로 만들면 자동으로 올라가고 목록에도 등록됩니다.
   → 직접 올릴 때는 themes.json 에도 {"id":"thema02","name":"이름"} 한 줄을 추가하세요.
     (themes.json 한 파일만 읽어서 목록이 빨리 뜹니다. 이 파일이 없으면 폴더를 하나씩 찾느라 느려집니다.)

2) 메뉴에 보일 이름을 바꾸고 싶으면 names.json 에 적으세요.
   {
     "thema01": "아침",
     "theme02": "저녁"
   }
   적지 않으면 파일 이름(theme02 등)이 그대로 보입니다.

3) 테마 파일에서 가져가는 것은 '배경/디자인 CSS' 와 '아이콘(ICON_DATA)' 뿐입니다.
   (페이지 전체가 바뀌거나 이동하지 않고, index.html 위에 덧씌워집니다.)
   - thema01.html 처럼 '원본 index 디자인 + 추가된 테마 CSS + ICON_DATA' 형태면 그대로 인식합니다.
   - 원하면 테마 CSS 를 /* @theme-start */ ... /* @theme-end */ 로 감싸 두세요. 그 사이만 사용합니다.

4) base-style.css 는 '원래 기본 디자인의 CSS' 사본입니다. 테마 파일에서 추가된 부분만
   골라내는 기준이므로 지우거나 수정하지 마세요.

※ 폴더 안 파일 목록은 서버에서 확인하므로, GitHub Pages 처럼 웹에 올린 상태에서 동작합니다.
   (내 컴퓨터에서 파일을 더블클릭해 열면 보안 때문에 테마 목록이 안 보일 수 있어요.)
