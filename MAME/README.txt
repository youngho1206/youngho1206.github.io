[마메게임 폴더 사용법]

1) 게임 롬(zip)을 이 폴더(MAME/)에 그대로 올리세요. (예: MAME/kof98.zip)
   - 롬은 압축을 풀지 말고 zip 그대로 올리세요. (MAME 0.78 / FinalBurn Neo 계열)
   - 게임 하나가 GitHub 100MB 이하여야 합니다.

2) 올린 롬은 '마메게임' 화면의 목록에 자동으로 나타납니다.
   - GitHub Pages 는 폴더 안 파일을 직접 볼 수 없어서, GitHub 의 파일 목록을 읽어 옵니다.
   - 목록이 안 뜨거나 게임 이름을 한글로 바꾸고 싶으면 games.json 에 적으세요.
     {"games":[{"file":"kof98.zip","title":"킹 오브 파이터98"}]}
   - 목록 오른쪽 위 ↻ 버튼으로 새로고침할 수 있습니다. (올린 직후엔 몇 분 걸릴 수 있어요)

3) 바이오스는 _bios 폴더에 넣습니다.
   - _bios/neogeo.zip 이 들어 있으면 네오지오 게임(킹 오브 파이터, 메탈슬러그 등)에 자동으로 합쳐져 실행됩니다.
   - 다른 바이오스가 필요한 게임이 있으면 같은 폴더에 넣어 두세요.

4) 내 기기의 롬(zip)을 직접 불러와 실행할 수도 있습니다. ('내 기기의 롬(zip) 불러오기' 버튼)

5) 게임이 안 열리면 자동으로 다른 엔진(FinalBurn Neo ↔ MAME 2003-Plus)으로 다시 시도하고,
   화면 위 '🧩 코어' 버튼으로 직접 바꿀 수도 있습니다.
