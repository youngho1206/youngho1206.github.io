iPhone · iPad 전용
아이폰,아이패드 전용 페이지입니다. 실행 시 문제가 있을 수 있습니다.

게임을 고른 뒤 📂 게임 파일 불러오기로 파일 앱의 ROM(.zip 포함)을 선택하세요.
시작 화면의 ▶ 버튼을 직접 한 번 눌러야 화면과 소리가 나옵니다.
아이폰에서 꽉 찬 화면으로 하려면 Safari 공유 버튼 → 홈 화면에 추가 후 실행하세요.

ROM 파일은 본인이 합법적으로 소유한 게임만 사용하세요. 이 사이트는 게임 파일을 제공하지 않습니다.
