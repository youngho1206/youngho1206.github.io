[BIOS 폴더 — 선택 사항]
이 폴더에는 BIOS 파일이 들어 있지 않습니다. 합법적으로 가지고 있는 BIOS 를 직접 올려두세요.

MAME 2003 에서 세가 ST-V 게임(twcup98 등)을 실행하려면 stvbios.zip 이 필요합니다.
  bios/stvbios.zip   ← 올려두면 ST-V 게임 실행 시 자동으로 사용됩니다.
올려두지 않았다면, ROM 선택 창에서 "게임 zip + stvbios.zip" 을 함께 선택(또는 끌어놓기) 하세요.
(MAME 0.78 / MAME 2003 용 romset 이어야 합니다. zip 은 압축을 풀지 말고 그대로 사용하세요.)
